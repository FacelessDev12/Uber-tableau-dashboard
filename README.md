# 🚕 Uber Trip Analysis Dashboard – Power BI

## 📊 Project Overview

This project is an **Uber Trip Analysis Dashboard created using Power BI**. 
It provides an interactive view of Uber bookings, revenue, trip distance, pickup locations, and booking patterns.

The dashboard helps understand **when people book rides, where they book from, how much they spend, and how far they travel**.

## 📌 Key KPIs

- **Total Bookings:** 148.77K
- **Total Booking Value:** 51.85M
- **Average Booking Value:** 508.3
- **Average Ride Distance:** 24.64

## 📈 Dashboard Features

- 📅 **Total Trips by Month** – Shows the number of trips throughout the year.
- 📍 **Revenue by Pickup Location** – Compares revenue from different pickup locations.
- 🕐 **Total Bookings by Hour** – Shows the busiest hours for Uber bookings.
- 📆 **Total Bookings by Day** – Compares bookings across different days of the week.
- 📏 **Trip Distance Distribution** – Shows how trips are distributed by distance.
- 💰 **Fare vs. Distance** – Shows the relationship between trip distance and booking value.
- 📊 **Average Fare by Distance Bucket** – Compares average fares across different distance ranges.
- 🎛️ **Interactive Filters** – Allows users to filter the dashboard by date and pickup location.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Excel / CSV

## 🎯 Project Objective

The main objective of this project is to analyze Uber trip data and create an **easy-to-understand interactive dashboard** that helps identify booking trends, revenue patterns, popular pickup locations, and trip-distance behavior.
