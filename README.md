# 🚕 Uber Trip Analysis Dashboard – Tableau

## 📊 Project Overview

This project is an **Uber Trip Analysis Dashboard created using Tableau**.  
The dashboard provides an interactive view of Uber bookings, revenue, trip distance, pickup locations, and booking patterns.

It helps understand **when people book rides, where they book from, how much they spend, and how far they travel**.

## 📌 Key KPIs

- **Total Bookings:** 148.77K
- **Total Booking Value:** 51.85M
- **Average Booking Value:** 508.3
- **Average Ride Distance:** 24.64

## 📈 Dashboard Features

- 📅 **Total Trips by Month** – Shows the number of trips throughout the year.
- 📍 **Revenue by Pickup Location** – Compares revenue from different pickup locations.
- 🕐 **Total Bookings by Hour** – Shows the busiest hours for Uber bookings.
- 📆 **Total Bookings by Day** – Compares bookings across different days of the week.
- 📏 **Trip Distance Distribution** – Shows the distribution of trips based on distance.
- 💰 **Fare vs. Distance** – Shows the relationship between ride distance and booking value.
- 📊 **Average Fare by Distance Bucket** – Compares average fares across different distance ranges.
- 🎛️ **Interactive Filters** – Allows users to filter the dashboard by date and pickup location.

## 🛠️ Tools & Technologies

- Tableau
- Data Visualization
- Data Analysis
- Excel / CSV

## 🎯 Project Objective

The main objective of this project is to analyze Uber trip data and create an **interactive Tableau dashboard** to identify booking trends, revenue patterns, popular pickup locations, and trip-distance behavior.
